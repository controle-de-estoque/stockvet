# Release Notes: StockVet

## Versão: 2.0.0
**Data:** 10 de Junho de 2026

### Resumo
O foco principal desta versão foi implementar o módulo de procedimentos e o disparo de e-mails, garantindo maior qualidade de vida e eficiência para o usuário final.

---

### 🚀 Funcionalidades Implementadas
* **Cadastro de procedimentos:** Criação de procedimentos para automatizar o cadastro de movimentações
* **Abate automático de produtos:** Abate automático de produtos (FEFO) utilizando procedimentos de referência
* **Disparo de e-mails:** Disparo de e-mails (HTML) para envio de notificações

### ⚠️ Bugs e Problemas Conhecidos
* **BUG-001:** O sistema permite o cadastro de cessionários com e-mail duplicado (Gravidade: Média).
* * **BUG-002:** O sistema sobrescreve lotes com o mesmo ID (Gravidade: Severa).

---
*Nota: Este documento reflete o progresso conforme registrado na primeira rodada de testes (Grupo 4) do projeto StockVet.*
